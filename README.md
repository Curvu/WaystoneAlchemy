# WaystoneAlchemy
 ExileCore2 Plugin

 Hotkey-Based Actions:

   - Alchemy Hotkey: Processes "Waystones" in the inventory, applying Alchemy Orbs and optionally Exalted Orbs.

   - Paranoia Hotkey: Applies "Distilled Paranoia" to rare Waystones if specific conditions are met.

   - Corruption Hotkey: Corrupts Waystones using a Corruption Orb.

   - Emergency Stop Hotkey: Stops all plugin actions when activated.

Inventory Management:

   - Retrieves specific items (e.g., Alchemy Orbs, Wisdom Scrolls) from the inventory.

   - Identifies items if necessary before applying transformations.

Waystone Handling:

   - Applies different transformations to Waystones based on their rarity (Normal, Magic, Rare).

   - Uses Alchemy Orbs, Regal Orbs, and Exalted Orbs to upgrade Waystones.

   - Corrupts Waystones using a Corruption Orb.

Distilled Paranoia Application:

   - Automates the process of applying "Distilled Paranoia" to rare Waystones, ensuring all required steps are executed.

Utility Methods:

   - Includes helper methods for interacting with the game UI, such as simulating mouse clicks and key presses.

The plugin is designed to streamline repetitive tasks, enhancing efficiency for players managing their inventory. It also includes safeguards, such as the emergency stop feature, to prevent unintended actions.
